PEBXEL REPLAY SITE: HOW TO PUT IT ONLINE
=========================================
Takes about 15 minutes. You need: a DigitalOcean account and a free DuckDNS account.

1. CREATE THE SERVER (DigitalOcean website)
   - Create > Droplets.
   - Region: whichever is closest to you.
   - Image: Ubuntu 24.04 (LTS).
   - Size: Basic > Regular > the $4/month one.
   - Authentication: Password. Choose a strong root password and save it somewhere.
   - Click Create Droplet. When it's ready, copy its IP address (looks like 164.90.12.34).

2. GET A FREE WEB ADDRESS (duckdns.org)
   - Sign in (Google, GitHub or Reddit login all work).
   - Type a name in the "sub domain" box, e.g. pebxel, and click "add domain".
   - In the "current ip" box next to it, paste the droplet's IP address and click "update ip".
   - Your address is now  pebxel.duckdns.org  (with your chosen name).

3. UPLOAD AND INSTALL (Windows PowerShell)
   Put pebxel-site.tgz in your Downloads folder, open PowerShell, and run these one at a time.
   Replace 164.90.12.34 with your droplet's IP and pebxel with your DuckDNS name.

     scp $HOME\Downloads\pebxel-site.tgz root@164.90.12.34:/root/
     ssh root@164.90.12.34
     tar xzf pebxel-site.tgz
     bash pebxel-site/setup.sh pebxel.duckdns.org

   - The first time, it asks "Are you sure you want to continue connecting?": type yes.
   - It asks for the root password from step 1 (nothing shows while you type; that's normal).
   - Setup takes a minute or two. At the end it prints two links:
       your site, and a private link for reading the feedback. Save the private one.
   - Type  exit  to leave the server.

4. READING FEEDBACK
   Open the private link in your browser. Each note has a link that jumps straight
   to that moment in the replay. "Download all as a file" gives a file you can send to Claude.

5. UPDATING THE GAMES LATER
   Claude will give you a new pebxel-site.tgz. Repeat step 3 exactly.
   Feedback already collected is kept.

If something goes wrong, copy what PowerShell printed and paste it to Claude.
